# Глоссарий

* Проблема - требования ФТС о доплате утилизационного сбора за автомобили, произведенные в Республике Казахстан. [Подробнее про проблему.](/avto_iz_KZ/index)

* ФТС - Федеральная таможенная служба.

* TПO - Таможенно-приходный ордер, документ по которому происходила оплата утилизационного сбора. Обязательный документ для получения ЭПТС. [Подробнее про ТПО.](/avto_iz_KZ/faq)

* ЭПТС - Электронный паспорт транспортного средства. Необходимый документ для эксплуатации автомобиля. [Подробнее про ЭПТС.](/avto_iz_KZ/epts)

* CT-KZ - Документ по форме CT-KZ, подтверждающий происхождение товара. Есть на каждый автомобиль, обсуждаемый в рамках нашего вопроса. [Подробнее про CT-KZ.](/avto_iz_KZ/ctkz)

* Постановление 1291 -  Положение о государственном надзоре за техническим состоянием самоходных машин и других видов техники в Российской Федерации. [Подробнее про Постановление 1291.](/avto_iz_KZ/1291)

* Дроп - человек, на которого оформлялся ТПО. [Подробнее.](/avto_iz_KZ/drop)

* ИМ40 - это кодовое обозначение таможенной процедуры выпуска товаров для внутреннего потребления. [Подробнее про ИМ40.](/avto_iz_KZ/im40)

* ИМ77 - это кодовое обозначение таможенной процедуры "Свободный склад".

* Свободный склад - это одновременно и таможенная процедура, и место, где хранится товар, выпущенный под данной таможенной процедурой. Товары декларируются и выпускаются таможней без уплаты таможенных платежей (пошлин, налогов, сборов).
