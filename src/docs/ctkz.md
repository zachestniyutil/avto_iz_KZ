# CT-KZ


Сертификат СТ-KZ (сертификат о происхождении товара) — документ специальной формы, подтверждающий, что страной происхождения товара является Казахстан.

На каждый ввезенный автомобиль есть CT-KZ. В графе 1 Производителем товара указана Республика Казахстан.
Сертификат предназначен для подтверждения страны происхождения товара и доли внутренней ценности.
