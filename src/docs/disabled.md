# Аннулирование ЭПТС

В результате требований ФТС ЭПТС может быть аннулирован.

Что это означает пока вызывает споры.

283-фз содержит информацию:

* Регистрация прекращается если постановка транспортного средства на государственный учет осуществлена на основании документов, признанных впоследствии поддельными (подложными) либо недействительными.

Считается ли недействительным аннулированный ЭПТС - не понятно.
